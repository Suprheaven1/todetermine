# Overview

Présence est une identité de travail pour une pratique de bien-être énergétique. Direction : nuit contemplative, composition éditoriale et halo orbital. Aucune promesse de guérison. Les visuels fournis illustrent une pratique, pas une efficacité médicale.

# Colors

Tokens CSS : --night #0b101e; --panel #111727; --mauve #33243e; --lavender #c1afd4; --ivory #f0ece7; --muted #a9acb9; --line #ffffff1f; --ink #171c2a.

# Themes

Un thème sombre intentionnel, sans bascule artificielle. Le formulaire utilise une surface ivoire pour créer une respiration.

# Typography

Georgia pour les titres et citations éditoriales; Arial pour le corps. Tailles fluides définies par --display, --heading, --body, --small. Italiques ponctuels.

# Layout

Largeur --container 1280px; marges --gutter clamp(24px,5vw,80px). Échelle --s1 à --s8. Deux colonnes asymétriques desktop, une colonne mobile à 760px.

# Elevation & Depth

Pas d'ombres de cartes. Profondeur par superposition de halos et lignes fines. Animation orbitale lente, désactivée avec prefers-reduced-motion.

# Shapes

Cercles pour l'identité, rayons --radius 2px pour les surfaces; boutons capsule --pill 999px.

# Components

Navigation, boutons, lignes de pratiques dépliantes, galerie avec dialogue accessible, FAQ native, formulaire validé. Contrôles min. 44px, focus visible et états actifs.

# Do's & Don'ts

Faire : phrases précises, grands espaces, illustrations légendées honnêtement, navigation clavier. Éviter : faux témoignages, preuves médicales, promesses, iconographie inquiétante, dégradés violets de remplissage, téléphone fictif. État de contact non configuré explicite.
